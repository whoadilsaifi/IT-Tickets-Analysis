# EXCEL-PROJECT — IT Tickets Analysis

An interactive Excel solution designed to analyze, track, and visualize IT Support Ticket performance, ticket volume trends, and operational resolution metrics.

---

## 📌 Project Overview

This project processes raw IT ticket logs to extract key service desk metrics—such as ticket status, resolution times, issue categories, and support performance. It helps IT teams monitor workload distribution and identify common technical bottlenecks.

---

## ✨ Key Features

* **Data Cleaning & Preprocessing:** Formatted raw IT ticket records (`IT Tickets.xlsx`) to ensure accurate calculation of metrics.
* **Service Desk Metrics:** Evaluated total ticket counts, open vs. resolved statuses, and ticket resolution performance across categories.
* **Dashboard Visualization:** Built interactive charts and visuals (`Deshboard-image.png`) for clear tracking of key performance indicators (KPIs).
* **Data Inspection:** Cleaned raw data records (`Data.png`) for streamlined reporting.

---

## 🛠️ Tools & Technologies Used

* **Spreadsheet Software:** Microsoft Excel / Google Sheets
* **Key Features:** Data Validation, Pivot Tables, Formulas & Functions, Charts
* **Version Control:** Git & GitHub
